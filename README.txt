GOLD AI TRADER PRO — WEB EDITION
================================

الملفات:
- index.html: واجهة الموقع العربية المتجاوبة للهاتف.
- worker.js: وسيط Cloudflare Worker لجلب شموع XAUUSD=X من Yahoo Finance.
- README.txt: خطوات النشر والتشغيل.

مهم جداً:
1) السعر المستخدم مرجعي من Yahoo Finance (XAUUSD=X)، وليس سعراً مضموناً مطابقاً لـ OW Markets أو أي وسيط.
2) لا يمكن ضمان قرب السعر من 3911 طوال الوقت. أثناء إعداد المشروع كان آخر سعر منشور في Kitco نحو 3918.10 بتاريخ 30 أكتوبر 2026، أي فرق نحو 7.10 دولارات عن 3911 (حوالي 0.18%)، لكن الأسعار تتغير بسرعة. هذا مرجع لحظة البحث وليس سعراً حياً داخل الموقع.
3) خاصية "معايرة مع سعر وسيطي" تحسب فرقاً تقريبياً ثابتاً من السعر المرجعي إلى سعر وسيطك الحالي. لا تجعل الشموع التاريخية مطابقة للوسيط، وقد يتغير الفرق.
4) لا توجد أوامر تداول آلية، ولا يطلب الموقع كلمة مرور أو API خاص بحساب التداول.
5) إشارات EMA20/EMA50 وRSI14 تعليمية وليست ضماناً للربح. لا تستخدمها دون اختبار تجريبي.
6) حساب مخاطرة الدولار لا يحسب اللوت؛ يلزم معرفة contract size وtick value وminimum volume والسبريد والعمولة لدى وسيطك.

طريقة النشر (من الهاتف):
أ) ارفع index.html إلى GitHub:
   - افتح https://github.com وأنشئ Repository جديداً باسم gold-ai-trader-pro
   - ارفع index.html إلى جذر المستودع.
   - Settings > Pages > Deploy from a branch > main > /(root) > Save.
ب) أنشئ Cloudflare Worker:
   - افتح https://dash.cloudflare.com ثم Workers & Pages > Create > Worker.
   - اختر Edit code، استبدل المحتوى بالكامل بمحتوى worker.js ثم Deploy.
   - انسخ رابط Worker الذي ينتهي عادة بـ workers.dev.
ج) ربط الواجهة بالـ Worker:
   - أفضل طريقة: ربط نطاقك بـ Cloudflare وإضافة Route للمسار /api/* إلى Worker.
   - إذا لم يكن لديك نطاق/Route، افتح index.html وابحث عن:
       let url=`/api/chart?symbol=XAUUSD%3DX&interval=${interval}&range=5d`;
     واستبدل `/api/chart?...` بعنوان Worker الكامل، مثال:
       https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev/api/chart?symbol=XAUUSD%3DX&interval=${interval}&range=5d
     ثم ارفع index.html المعدل إلى GitHub من جديد.
د) افتح رابط GitHub Pages. اسمح بالتحديث، وتأكد أن الحالة تظهر "متصل".

إذا ظهرت "تعذر الاتصال":
- افتح رابط Worker نفسه للتأكد أنه يعمل.
- جرّب رابط /api/chart?symbol=XAUUSD%3DX&interval=5m&range=5d على Worker.
- قد يقيّد Yahoo Finance الوصول أو يغير واجهة البيانات؛ عندها نحتاج مزود API بديل. لا تعرض أي سعر على أنه مباشر إذا فشل الاتصال.

معايرة:
بعد ظهور السعر المرجعي، أدخل سعر XAUUSD الظاهر في MT5 في خانة المعايرة واضغط تطبيق. افعل ذلك فقط عندما تقارن السعرين في نفس اللحظة تقريباً. فرق المعايرة مؤقت وليس ضماناً لمطابقة الوسيط.

الوقت:
يعرض الموقع توقيت Africa/Tripoli. جلسات آسيا/لندن/نيويورك تقريبية وتتأثر بالتوقيت الصيفي والعطلات.
